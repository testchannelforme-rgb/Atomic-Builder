# Atomic Builder V3 ⚛️

A Discord server-building and administration toolbox.

## Highlights
- Custom text, voice and forum channels
- Categories: create, rename, safe-delete
- Roles: create, color, rename, assign/remove, delete
- Lock/unlock and hide/unhide
- Per-role channel permissions
- Channel editing, cloning and moving
- Purge and server info
- JSON structure backup and rebuild
- Atomic.Dev and community templates
- Interactive `/wizard`
- Administrator-only command safeguards
- Destructive actions require confirmation

## Run
Keep your existing `.env`, then:

```bash
npm install
npm start
```

Never commit `.env` or your Discord bot token.
